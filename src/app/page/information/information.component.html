For KFF - Zahlenfolgen the algorithm is implemented as followed:
By default it will generate {{this._zfService.amountOfTasks}} tasks.
Each task contains {{this._zfService.amountGivenNumbers}} given numbers and {{this._zfService.amountGivenSolutionNumbers}} hidden numbers.
The {{this._zfService.amountGivenSolutionNumbers}} hidden numbers are related to the given numbers. For the task {{this._zfService.amountGivenAnswersOptions}} answer options will be generated including one options that none of the solutions is correct. Since this should not occur that often, their is a probability setting for option E (default is 0.05 = 5%).
The current value for the probability of Option E being the correct answer is {{this._zfService.nonCorrectAnswerIsCorrectProbability}} = {{this._zfService.nonCorrectAnswerIsCorrectProbability*100}}%. You max change the probability in the settings tab.
TIP: The generation of the wrong answers is not implemented well yet - so for practice purpose try to find the solution without the exclusion process.
Each individual task will be generated by a random picked system. There are 23 different systems.
